 How we'll work

For every section, I'll provide three outputs:

1. Content — the polished copy for recruiters.
2. Design — layout, UX, animations, and visual hierarchy.
3. Implementation — the exact components, folder structure, and technical guidance for your Next.js + Tailwind + shadcn/ui + MDX stack.

This way, each AI session produces a complete, self-contained piece that you can implement immediately, and by the end we'll have a cohesive, production-quality portfolio rather than disconnected pages.
